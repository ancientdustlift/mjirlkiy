# Legends of Seltso

Fabric mod for Minecraft 1.21.1 (formerly "Kalabushkin"). The mod id is still `kalabushkin`, so existing worlds keep working.

- **Kalabushkin** fist-bumps you, drops a carpenter's plane or mallet and leaves a spirit that follows you.
- **Vlad Logutov** rides his mountain bike. When he sees a player he rides up, puts a foot down and asks his question. He drops the **Shatuni**, a two-handed crankset: hold use to spin it like a circular saw.

Build with `./gradlew build` (Java 21). Textures and the mod icon are generated by `python3 tools/generate_textures.py` and `python3 tools/generate_weapons.py` (need Pillow).
