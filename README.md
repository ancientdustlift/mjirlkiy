# Legends of Seltso

Fabric mod for Minecraft 1.21.1 (formerly "Kalabushkin"). The mod id is still `kalabushkin`, so existing worlds keep working.

- **Kalabushkin** fist-bumps you, drops architect's tools and leaves a spirit that follows you.
- **Vlad Logutov** rides his mountain bike. When he sees a player he stops, puts a foot down and asks his question.

Build with `./gradlew build` (Java 21). Textures and the mod icon are generated by `python3 tools/generate_textures.py` (needs Pillow). Vlad's face comes from `tools/vlad_face.png`.
